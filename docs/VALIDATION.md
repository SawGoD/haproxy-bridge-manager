# Проверка сборки — 12 ноября 2026

Выполнено локально без обращения к продуктивному серверу:

- `go test -race ./...` — пройдено.
- `go vet ./...` — пройдено.
- `make integration` — два теста с настоящим `haproxy:3.2`, пройдено.
- Валидный кандидат принят, невалидный отклонён официальным HAProxy validator.
- Проверено сохранение старого inode у single-file bind после rename.
- Проверены обнаружение stale content, запрет restart и Compose recreate только тестового сервиса.
- Проверен Docker graceful: PID 1 master-worker, USR2, новый worker.
- Собраны статические ELF-бинарники Linux amd64/arm64 и SHA256SUMS.
- Ubuntu 24.04 arm64: запуск бинарника, таблица четырёх нод, UNKNOWN без Runtime API, редактор, выход и восстановление терминала.
- После smoke-теста исправлена таблица для 80 колонок; повторная проверка пройдена.
- Mock-тесты подтверждают отказ Native Apply при несовпадении systemd ExecStart и управляемого config.

Не выполнены: работа через реальное SSH-соединение на целевом сервере, проверка его фактического `haproxy.cfg`, mounts, ACL и прав. Исходный продуктивный файл не предоставлялся и не читался. Проверочные fixtures не заменяют проверку целевой установки.

Ограничения версии: Native graceful не поддержан; сложные quoting/escaping, conditional blocks, default-server и server-template блокируют редактор; multi-config/custom-entrypoint Docker validator блокируется; автоматический rollback доступен к подтверждённой точке текущего сеанса. Изменения в продуктивной среде требуют отдельного разрешения.

## Обновление интерфейса — 13 ноября 2026

- Главный экран переработан: таблица, детали выбранного маршрута, контекстные действия.
- Settings и первый запуск используют поля по разделам; сырой TOML не показывается.
- Серверы редактируются в отдельных формах с переключателями; порядок меняется Ctrl+↑/↓.
- Тесты покрывают отмену Settings, добавление сервера, подтверждённое удаление, компактный diff и размеры экранов 80×24/120×36.
- Выбор отмечается символом ›, в том числе без цвета.
